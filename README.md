| Công cụ | Phiên bản |

| IDE | Dev-C++ 5.11 |
| Hệ điều hành | Windows |

---

## 📌 Nội dung chính

### A — Hàm
Các bài tập về định nghĩa, gọi hàm, truyền tham số, đệ quy.

### C — Mảng và Con trỏ
Thao tác trên mảng 1 chiều, 2 chiều. Con trỏ, địa chỉ, cấp phát động (`malloc`, `free`).

### E — Danh Sách Liên Kết
Cài đặt singly linked list đầy đủ: khởi tạo, thêm đầu/cuối/giữa, xóa, tìm kiếm, sắp xếp, in danh sách.

### F — Thao Tác Trên Tệp Tin
Đọc/ghi file văn bản và file nhị phân với `fopen`, `fprintf`, `fscanf`, `fread`, `fwrite`.

### BTL — Bài Tập Lớn
Chương trình quản lý tích hợp các cấu trúc dữ liệu và thao tác file. Giao diện menu phân cấp, gồm các bài tập E1–E5 và F2–F8.

---

## 🚀 Cách chạy

1. Mở file `.dev` bằng **Dev-C++**
2. Nhấn **F11** để Compile & Run
3. Hoặc compile thủ công bằng GCC:

```bash
gcc main.c -o main.exe
./main.exe
```
