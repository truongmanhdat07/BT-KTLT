# Bài tập lớn - Kỹ thuật lập trình (KTLT)

## Giới thiệu
Repository lưu các bài tập và bài tập lớn môn Kỹ thuật lập trình viết bằng ngôn ngữ C.

Các bài được tổ chức theo dạng module:
- `main.c`
- `.c`
- `.h`
